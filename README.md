# Projet Moustass – Module Auth

## Objectif
Fournir un module d’authentification sécurisé prêt à être intégré au projet Moustass.

## Fonctionnalités
- Authentification utilisateurs (JWT)
- Gestion des rôles (ADMIN / CLIENT)
- Interface admin (CRUD utilisateurs)
- API REST sécurisée
- Backup et restauration
- Route de test /health

## Stack technique
- Backend : Laravel
- Frontend : React
- Base de données : MySQL
- Authentification : JWT
- Versioning : GitHub

## Organisation
Projet réalisé en binôme avec workflow Git (branches, pull requests).
